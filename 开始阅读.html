页面怎么用

每门课只有一个页面。正文按句子作用用荧光笔分色：紫色结论、蓝色方法、绿色例子、橙色易错、黄色概念（加粗术语为红字下划线）；另有“词语荧光”帮助跳读。

右侧是阅读面板。右上为目录和三种视图，点面板顶部切换：

  • 概念：当前小节最基本的概念及依赖，箭头 A → B 表示 B 用到 A，“← X”是前面小节的概念；点概念跳到原文。
  • 大纲：当前章的小节树，展开当前小节的定义、定理、结论、易错、例题、带框公式和关键词。
  • 地图：全部荧光句子的卡片，点卡片跳到原文。

面板底部：“词”换词语荧光的颜色，或改成只加粗；“密”开关每句自动补的浅荧光；五个颜色按钮开关对应的荧光，双击只看一类；“原文”去掉全部荧光。“手写区”在右下给 Mac 触控板手写小窗留位置（拖紫点校准，双击恢复默认）；手写区关闭时，那里显示本单元的“智慧”树。面板右上的“×”收起面板，回到原讲义的左侧目录版面；右上角“阅读面板”按钮可再打开。这些设置按页面记住。

如何让阅读比听课更有效

每次选一个知识单元，不必一口气读完整门课。

  1. 先试 5–10 分钟。 直接做文末题；会做且能解释条件的部分，跳过重读。
  2. 只补薄弱处。 回到出错小节，读概念与推导，遮住例题解答重新做一遍。
  3. 闭卷复现。 用一张纸写出“什么时候用、怎样开始、怎样检查”，再做自测。
  4. 隔天再测错题。 如果仍不会，记录具体障碍：概念、模型、运算、单位还是符号；按障碍修补，不按阅读页数衡量进度。

能独立做出题并说明适用条件，才算这个单元学完。建议学习时间只是安排参考，不代表保证在固定分钟数内掌握。公式和例题都可回到各讲义末尾的本地来源定位。

先学哪些

若五门都从零开始，可先各完成一个基础单元：

  • 复变：复数形式 → 极限路径 → 可导与解析 → C–R → 柯西积分定理 → 柯西积分公式与高阶导数。
  • 概率：事件翻译 → 分块与容斥 → 等可能模型 → 不放回抽样。
  • 物理：矢量叠加 → 对称性与高斯面 → 电势差 → 梯度。
  • 电路：参考方向 → 吸收功率 → RLC 微分积分 → 分段波形。
  • 实验：均值与标准差 → A/B 类 → 传播 → 结果修约。

跨课联系可以减少重复学习：物理的电势差帮助理解电路电压；微积分中的导数与面积对应电感电压、电容电压；概率中的分散程度帮助理解实验标准差。复变中的 C–R 与后续调和函数，则与静电场中的势函数有联系，但不提前把不同条件下的结论混用。

材料核对后的重要提醒

  • 复变： 转写里的“解析映射把圆映成圆”不能作为一般结论；C–R 的充分性有可微性前提。讲义已说明。
  • 概率： 0919 文件是一页手写作答，不含完整题干，不当作官方答案。
  • 物理： 已读取转写内嵌 PPT，恢复密度 A/r 的球壳原题和课堂梯度例题；老师的电通量引入、一般求场路线和梯度推导已融入正文。
  • 电路： 负值必须连同参考方向解释；电源空载时要区分源支路与外部负载电流。
  • 实验： PPT 第 31 页六次读数均值应为 0.249 mm，零位修正后 0.244 mm；圆环体积例的修约与后文规则不一致。报告模板的评分比例也与 2025 PPT 不同，差异已逐项列明。

正文中的新例题、自测与解释为重编学习内容，既不冒充教师原话，也不冒充完整教材。原始课本、课件和转写保持原样。
